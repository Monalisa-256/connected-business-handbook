# Visual atlas: the business workforce in large diagrams

Every diagram in this atlas is **Mermaid written directly in Markdown**. GitHub renders it without requiring PNG files, SVG uploads, scripts or external image servers. The diagrams are intentionally wide and detailed: open the page on a desktop when possible, or use your browser's zoom controls. Each page provides a short explanation for readers who prefer text.

**How to read the diagrams:** A rectangle is a task, a diamond is a decision, and a rounded or database-shaped element generally represents a source or record. Arrows are handoffs or flows of information. They **do not** mean that every tool supports every connection. Read each diagram as a design pattern to adapt and test.

The diagrams show idealized, supervised processes. They do not execute actions, guarantee safety, or replace vendor documentation.
