# Plain-English glossary

**Agent / digital employee:** A system assigned a job that can use instructions, information and tools to carry it out. It is not a human employee.

**API:** A structured doorway software uses to ask another piece of software for information or actions.

**App / product:** The interface people use, such as a chat product or a visual workflow builder. An app may use several models.

**Approval:** A deliberate decision by an authorized person before a sensitive action occurs.

**Automation:** A set of steps that run after an event or on a schedule, often without a person repeating each step.

**Client / host (MCP):** The app or software that connects to and uses tools offered by MCP services.

**Connection / connector:** A supported link between products, such as a calendar and a workflow builder.

**Context:** Information supplied to a model so it can understand the current request.

**Document extraction:** Finding specified information in a document, such as invoice number and amount.

**Handoff:** Transferring a job, facts and next steps from one specialist or person to another.

**Human in the loop:** A person reviews, corrects or approves part of the workflow.

**Knowledge base:** A maintained collection of documents or records used to answer questions.

**MCP (Model Context Protocol):** A standard for compatible apps to discover and use tools, resources and prompts provided by connected services.

**MCP server:** The service offering those tools or resources. It may be remote and hosted by a provider; it is not necessarily something the business owner runs.

**Model:** The part of the system trained to interpret input and produce responses or other outputs.

**Multimodal:** Handling more than one form of material, such as text, speech, images, documents or video.

**OCR:** Optical character recognition: turning visible writing in scans or photographs into text.

**Prompt / instructions:** The words that explain what to do, how to respond, and what boundaries apply.

**Prompt injection:** Malicious or misleading instructions placed inside material that the assistant reads, such as a web page or email.

**RAG / retrieval:** Looking up relevant information from approved sources before preparing an answer.

**Read-only:** Can see or search information but cannot edit it through that permission.

**Source of truth:** The company system designated as authoritative for a particular fact, such as today's stock quantity.

**Task register:** The list of work items, owners, progress and confirmed outcomes.

**Tool:** A specific function the assistant can use, such as search, create task or read calendar.

**Visual workflow:** A sequence made by connecting steps in a graphical editor rather than writing software.

**Workforce:** Several specialized assistants and workflows organized to handle connected business tasks.

## More terms you will meet in product demonstrations

**Action receipt:** Evidence from a connected system that an operation occurred, such as the ID of a newly created appointment or CRM record. A written claim of completion is not a receipt.

**Approval checkpoint:** A deliberate pause before a restricted action. The next step must respect rejection as well as approval.

**Context window:** The amount of information a model can process within one request. It is not a durable company archive or guaranteed memory.

**Grounded answer:** An answer based on identified, relevant evidence rather than unsupported recollection.

**Handoff:** Moving work from one responsible party to another while carrying the task ID, facts, outstanding questions and approval state.

**Idempotency:** The principle that repeating the same event should not produce an unintended duplicate action. For example, a payment notification arriving twice must not create two refunds.

**MCP host/client/server:** Parts of the connection standard: the application someone uses, the component that talks to an MCP service, and the service exposing tools or information.

**Negative permission test:** An attempt to do something the system must block, such as deleting records when only read access was approved.

**Retrieval:** Finding relevant information from approved documents or databases when a question is asked. Search results can still be wrong, outdated or incomplete.

**Source of truth:** The authorized record used for a particular fact: inventory for stock, accounting system for ledger entries, calendar for appointments.

**Tool invocation:** A request by an assistant to use a connected function. Its success should be established from the returned result or system records.

**Voice handoff:** Transferring a live conversation to a person or channel. Support differs by provider and channel; a telephone handoff feature does not automatically work on WhatsApp.
