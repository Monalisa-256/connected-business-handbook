## Completed example: handling service inquiries

| Field | Example answer |
|---|---|
| Business problem | Staff spend the first hour each day sorting mixed inquiries |
| Trigger | New email to a shared service mailbox |
| Input | Email body, subject and attachments if supported |
| Source of truth | Current service catalog and service policy |
| Permitted first action | Categorize message and create an internal task draft |
| Restricted actions | No refunds, no outgoing promises, no deletion |
| Expected result | Assigned task with source message ID and confidence notes |
| Human owner | Customer service supervisor |
| Stop condition | Customer details not authorized, source unavailable or tool failure |
| Baseline | 45 minutes per workday spent manually sorting |
| Review date | Two weeks after supervised trial starts |
